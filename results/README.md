# Results

Put the files produced by the evaluation scripts here after you run them:

- `evaluation_results_*.json` from `python evaluate.py` (and `--set holdout`)
- `experiment_results*.csv` from `python experiment.py`
- `baseline_300_50.json`: the evaluation run at 300-word passages, for comparison

`nist_test_dataset_fixed.json` is the 15-question test set (with reference answers and physical page numbers) used before the questions were moved into `evaluate.py`.
